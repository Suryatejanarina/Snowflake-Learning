# Snowflake Learning

My Snowflake SQL practice scripts from my training, organized by topic. Each script has comments explaining the concept, so it can double as a quick revision guide.

## Files

| File | Topic |
|---|---|
| 01_database_schema_table_basics.sql | Database, schema, table, and basic DML (insert, update, delete) |
| 02_file_formats.sql | File formats: creating and using file formats for loading data |
| 03_table_types.sql | Table types: Permanent, Transient, Temporary, and External |
| 04_stages.sql | Stages: User, Table, Named Internal, and External |


## How to use
Run the scripts in order in a Snowflake worksheet. You need a running warehouse and a role that can create databases.
